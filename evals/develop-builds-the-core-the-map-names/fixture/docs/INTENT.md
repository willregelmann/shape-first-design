# Chores

A chore tracker for a shared household: nobody has to remember whose turn it is.

Whenever a chore comes due, Chores answers one question: **whose turn is it, and does everyone know?**

Writing chores on a fridge list is only half the job. The list says what needs doing, not who's doing it this time, and it never reminds anyone. Turns drift: one person ends up doing the bins every week while another hasn't touched them in a month.

So Chores keeps each chore with the people who share it and when it's next due, hands the turn to the next person each time it's done, and reminds whoever has the turn when it comes due.

If a chore comes due and the person whose turn it is wasn't told, Chores has failed at the one thing it exists to do.
