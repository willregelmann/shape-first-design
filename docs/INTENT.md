# Shape-First Design

Agent skills for building software shape first: find what a project is made of, then keep the code to it.

A strong mental model produces minimal bloat. Capable models write excellent functions and still lose the model: a new type for a case an existing thing already covers, three names for one idea, a rule checked in one caller and forgotten in the next. So Shape-First Design finds the few things a project is made of with the person who has the idea, and writes what must always hold about them as a map anyone can read without the code. The map gives a builder the right core to start from.
